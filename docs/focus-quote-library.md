# MyTime 状态专注句子库

> 版本：v2.0（全量重写 · 208 句）
> 用途：用户进入"专注"页时，按当天状态随机显示一句话。
> 状态：已润色，待接入页面。

## 使用规则

- 当天选择状态后，只从对应分组随机抽取；每次打开专注页时都可获得一句新的陪伴。
- 用户切换状态后，下一次打开专注页会从新状态对应的分组随机抽取。
- 如当天触发阶段完成或项目完成庆祝，优先使用"小胜即庆"或"大胜狂欢"组。
- 没有选择状态时，从"无状态 / 世界很好"组抽取。
- 文案禁区：不说教、不命令、不评判、不使用"你应该""别浪费""快去""必须"等口吻。
- 除特别标注的古诗词与国际经典外，均为 MyTime 原创文案。
- 每个状态建议界面只展示句子正文；作者与出处在"换一句 / 查看出处"中展示。

## 轻哲理补充池（可按任何状态低频抽取）

> 不绑定具体情绪，适用于任何时刻的安静一击。

- 专注不是把世界关在门外，是把自己慢慢还给自己。
- 一件小事被认真完成，就足以让一天有了形状。
- 进度不总是一条直线，但每一次停留都有意义。
- 时间不是用来追赶自己的，是用来陪自己抵达的。
- 所有看似普通的日子，都在悄悄组成你想成为的人。
- 你不必一直发光，也可以先把自己的灯打开。
- 把注意力放回眼前，世界会从模糊里一点点显形。
- 有空白的生活，才装得下新的东西。
- 走得慢的人，也能看见路边的花。
- 没有被看见的努力，也会在某一天变成你的底气。
- 结果很重要，但你在路上长出来的部分也很重要。
- 认真过的每一分钟，不会消失在今天里。
- 人会在重复里慢慢变得可靠，日子也会因此变得明亮。
- 有些变化很轻，轻到只有回头看时才会发现。
- 今天做不了满分，也可以留下自己的签名。
- 生活不是等到万事俱备才开始，它常常在不完美里缓缓展开。
- 不是所有的坚持都有回声，但坚持本身已经是回答。
- 焦虑说明你在乎，在乎说明你认真，认真的东西值得慢一点。
- 你此刻的专注，是未来某天回头看时的"原来从那时就开始了"。
- 做完比做好更值得庆祝，因为"完成"本身就是一种勇敢。
