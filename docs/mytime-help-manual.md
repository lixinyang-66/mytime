# MyTime 帮助手册

这是站内 `/help` 页面的维护源稿。页面以“研究生毕业论文”和“三个月健康减重”为例，说明 MyTime 的完整工作流：建立空间、新建项目、确认计划图、配置本周专注、结束专注时选择项目并填写完成记录、查看项目与每周 AI 复盘。

## 核心逻辑

- 项目状态：所有阶段完成为“已完成”；本周推进项目中被选择为“进行中”；未完成但未被本周选择为“暂缓”。
- 项目进度：以用户的专注记录、完成时长与内容为依据，由 DeepSeek 给出进度建议；不可用时保留可见的备用结果。
- AI 计划：先检索系统知识库，再请求 DeepSeek。无知识库上下文时不调用模型，直接走本地备用计划。
- 本周专注：用户设置一段可重复投入的时间，并分配到本周要推进的各项目；不是逐日排程。

## 页面维护说明

站内页面实现于 `src/app/help/page.tsx`，登录页入口在 `src/components/LoginForm.tsx`。示例数据仅用于帮助用户理解流程，不会访问或修改用户空间中的真实数据。
